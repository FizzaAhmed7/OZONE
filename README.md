# 🌍 Ozone Pollution Analysis  

This project analyzes **EPA ozone pollution data in California (2024)**.  
It focuses on cleaning, exploring, and visualizing air quality data to uncover trends and hotspots.  

## 📌 Objectives  
- Clean and validate dataset  
- Explore daily and regional ozone pollution patterns  
- Compare weekday vs weekend air quality  
- Create heatmaps to identify pollution hotspots  

## 🛠️ Tools Used  
- Python  
- Pandas  
- Matplotlib  
- Folium  
- Jupyter Notebook  

## 🔎 Key Insights  
- Certain regions show consistently high ozone levels  
- Weekday pollution is slightly higher than weekends  
- Geospatial heatmaps highlight major pollution hotspots
